# SAME

A fee-fed flywheel on Solana: trading fees return as purchases, and what they buy is retired for good.

## Overview

SAME is a Solana token built around a single loop. Fees from trading fund purchases of the token, and the purchased supply is permanently retired. The website shows a live market view and a plain record of which facts are confirmed.

## Features

- Live Solana market table, top ten by 24h volume, with a ticker
- Contract slot that stays inert until an address is stated
- Register of external facts, each one stated, absent or unconfirmed
- Static build, deployable from `dist/`
