# SAME Whitepaper

## Vision and mission

SAME aims to make a token whose supply shrinks as a direct consequence of being used. The mission is a loop that runs without anyone's attention and that anyone can verify on chain.

## How it works

Trading produces fees. Fees fund purchases of the token. Each purchase is sent to an address that cannot spend it, so supply only moves downward.
